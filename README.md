# Sistema de Gestión de Eventos (EventosAPI)

## Descripción del Proyecto
Plataforma integral diseñada para la gestión de eventos y la reserva de entradas. El sistema está compuesto por una API RESTful que sirve como backend, un panel web administrativo para organizadores, y una aplicación móvil para que los usuarios finales puedan explorar y reservar eventos.

## Arquitectura del Proyecto
El proyecto está dividido en tres partes principales:
1.  **API REST (Backend):** Desarrollada en ASP.NET Core, maneja la lógica de negocio, autenticación y acceso a datos.
2.  **Panel Web (Frontend):** Interfaz administrativa para la gestión de eventos (Node.js).
3.  **App Móvil:** Aplicación para usuarios finales (React Native).

## Tecnologías Utilizadas
*   **Backend:** C#, ASP.NET Core, Entity Framework Core
*   **Base de Datos:** SQL Server
*   **Frontend Web:** Node.js, Express, (Motor de plantillas o React)
*   **App Móvil:** React Native
*   **Autenticación:** JWT (JSON Web Tokens)
